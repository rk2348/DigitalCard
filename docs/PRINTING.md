# イラストからカードを作って印刷する

1. Webページの「イラストからカードを作る」を選びます。事前のQR印刷は不要です。
2. 別の紙に描いたイラストを撮影するか、スキャンしたPNG・JPEG・WebP画像を読み込みます。
3. キャラクターを囲んで切り抜き、名前を入力して登録します。
4. 保存が成功したら「完成したカードを印刷」を選びます。
5. プレビューの「印刷 / PDFに保存」でプリンターまたはPDF保存を選択します。

カードは約200×279mmに拡大し、A4用紙に1枚を大きく配置します。用紙はA4・縦向き、印刷倍率は100%、ヘッダーとフッターはオフにしてください。左右5mmの余白を確保し、縦横比を保って用紙の中央に配置します。イラスト、名前、能力値、スキル、対戦用QRを含みます。QRは保存済みカードのIDとシード値を持ち、「対戦する」から読み取れます。

プリンターを使えるPCで作成・印刷するか、端末の印刷機能を利用してください。PDF保存後に別のPCから印刷することもできます。印刷のキャンセル後もプレビューから再実行できます。公開環境に反映するには、従来のdocs一式に加え `card-print.js` と `vendor/qrcode.js` も配信してください。

## 開発時の検証

Unityの **登録カード一覧 → カードを選択 →「カードを見る・印刷」** から、登録済みカードのプレビューも開けます。保存済みのイラスト・能力値・QRをブラウザで表示し、印刷やPDF保存ができます。トーナメントのカード詳細からも同じ操作ができます。プレビューはPC内の `Application.persistentDataPath/PrintedCards` に保存され、一覧で取得したデータから作るため、開く時のWebサイトへの接続は不要です。

Unity用のテンプレートとカード画像は `Assets/StreamingAssets/CardPrinting` に同梱しています。Webのカードデザインや印刷処理を変更した時は `node tools/build_card_print_template.cjs` で更新してください。

`node tools/test_card_print.cjs` はローカルのChromeを使って、カード作成、保存失敗時の再試行、印刷サイズ、印刷専用表示、次のカードの作成を検証します。Firebaseと印刷ダイアログはスタブ化し、実際の保存や紙の印刷は行いません。結果画像とPDFは `Temp/card-print-test/` に出力します。

QR生成にはMITライセンスのqrcode-generator 1.4.4を同梱しています（著作権表示は `vendor/qrcode.js`）。
