# 紹介動画の構成

Unityの構成アセット `Assets/Introduction/IntroductionSequence.asset` が編集元です。初期構成は以下の75秒です。

| 時間 | 演出 | 見せ方 |
|---|---|---|
| 0–7秒 | Hook | 相棒を寄りのカメラと光の粒で印象づける |
| 7–15秒 | Title | 2体とアリーナを引きで見せ、作品名を表示 |
| 15–25秒 | Capture | UnityのカードUIに作品を表示し、スキャンラインを動かす |
| 25–34秒 | Name | カードの名前を文字送りで表示し、相棒として紹介 |
| 34–43秒 | Summon | 召喚サークルと光の粒の中から2体が登場 |
| 43–54秒 | Choice | 強・普・弱の選択とHP表示で駆け引きを説明 |
| 54–66秒 | Battle | 光の攻撃、被弾、HP減少、カメラ移動で盛り上げる |
| 66–75秒 | Closing | 2体からカメラを引き、「次の主役は、キミの作品。」で締める |

各カットの長さ・順番・字幕・カメラは制作ウィンドウで編集できます。登録と対戦は説明用のUnityアニメーションです。
