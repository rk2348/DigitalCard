# Unity内で制作する紹介動画

映像の構成・3D演出・カメラ・字幕・BGM合成・MP4エンコードをUnityで行います。録画映像、連番の素材画像、Web画面のスクリーンショット、FFmpegは使用しません。

## 操作

1. Unityメニュー「オリサモ → 紹介動画 → 動画制作ウィンドウ」を開く。
2. 「Unity動画シーンを開く / 初期作成」を押す。
3. カットを選ぶかスライダーでシークする。映像プレビューは無音。
4. 「カット構成」を展開して、並び順・秒数・見出し・説明・カメラ始点/終点・注視点・画角を変更する。
5. BGMと音量を選び、「構成を保存」。
6. 「UnityからMP4を書き出す（BGM付き）」を押す。

構成は `Assets/Introduction/IntroductionSequence.asset`、シーンは `Assets/Scenes/Introduction.unity`。シーンをPlayすると、Unityオブジェクトを動かしてBGM付きで再生します。カットを追加する場合はKindで演出の種類を選択してください。1カットは1秒以上です。

初期構成は75秒・8カット、出力は1280×720・30fpsです。時間を変更すると出力尺も変わります。書き出しはエディター内で行い、進捗表示から中断できます。

## 制作の仕組み

- `IntroductionSequence`: カット順・長さ・字幕・カメラ設定・BGMを保存するScriptableObject。
- `IntroductionDirector`: 指定時刻から、キャラクター、召喚光、攻撃、HP、カード、字幕、カメラの状態を直接計算。同じ時刻は同じ映像になるため、途中シークと書き出しで演出が一致する。
- 既存ゲームの `DemoCharacterArt` と `PhotoSculpture` でキャラクターの画像と立体メッシュをUnity内で生成。アリーナはUnityのメッシュ・Primitive・LineRenderer、画面表示はCanvasで構築する。
- `IntroductionStudio`: UnityカメラからRenderTextureへ描画し、Unity標準 `UnityEditor.Media.MediaEncoder` に映像とPCM音声を渡してMP4にする。外部エンコーダーや中間の連番画像は不要。
- BGMはAudioClipから読み出し、音量調整、ループ、冒頭1秒・末尾4秒のフェードをUnity内で処理する。未指定の場合は映像のみを出力する。

登録画面と対戦は紹介動画向けにUnity内で構成した演出です。本番のスマートフォン操作・オンライン対戦の録画ではありません。登録・通信処理は実行しません。

生成されるステージは一時オブジェクトで、シーンを開いたままプレビューやPlayをすると組み立てられます。構成アセットとシーンのカメラ・フォント参照が制作データです。

## 一括出力

Unityがこのプロジェクトを開いている場合は「オリサモ → 紹介動画 → 標準構成を検証して書き出す」。保存先は `オリジナルサモナー_UnityNative.mp4`。

Unityを閉じている場合は `tools/export_introduction.ps1` を実行できます。スクリプトはUnityを起動するだけで、映像作成とエンコードはすべてUnity側で行います。

標準構成の検証は、全カットのプレビュー画像と、順序を変えてシークした際の同一フレーム一致を確認してから出力します。検証画像は `tmp/native-review/` に置きます。

以前の `紹介動画_Studio.mp4` と `紹介動画.mp4` は旧方式の出力です。現在のUnity制作機能からは参照しません。
